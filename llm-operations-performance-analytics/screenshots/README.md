# Screenshots

Export or capture two clean report views and save them here:

```text
executive-overview.png
optimization-opportunities.png
```

Recommended state for portfolio screenshots:

- no accidental team/task filters selected
- full report canvas visible
- no Power BI editor side panels if possible
- readable titles and labels
- `Executive Overview` should show organization-wide KPIs
- `Optimization Opportunities` should show the unfiltered model/task overview

Optional third screenshot:

```text
optimization-drilldown.png
```

This can demonstrate an interactive drill-down such as a selected team and task.
