# Pre-CV / GitHub checklist

Before adding this project to the CV:

- [ ] `README.md` renders correctly on GitHub.
- [ ] `generate_data.py` runs successfully.
- [ ] `.env` is NOT committed.
- [ ] generated `*.csv` files are NOT committed.
- [ ] SQL Server starts with `docker compose up -d`.
- [ ] SQL pipeline loads 5,000,000 records.
- [ ] final `null_costs` validation returns `0`.
- [ ] Power BI report opens without broken visuals.
- [ ] `Executive Overview` screenshot is exported with no accidental filters.
- [ ] `Optimization Opportunities` screenshot is exported with no accidental filters.
- [ ] PBIX file is placed in `powerbi/` if its size is suitable for GitHub.
- [ ] no passwords, API keys, personal data, or private company data are present.
- [ ] Business Insights section is included in README.
- [ ] Repository is public and the GitHub link works from an incognito/private browser.
